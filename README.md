Developed a Transporter Performance Dashboard using Python and Power BI to monitor 10+ logistics KPIs, including delivery status, delays, GPS availability, transit time, and transporter performance.
Cleaned, transformed, and validated 10,000+ logistics records from 3+ operational data sources, improving data consistency and supporting reliable KPI reporting.
Automated logistics reporting workflows and Power BI dashboards, reducing manual reporting effort by ~60% and improving report generation turnaround by ~70%.
Analyzed transporter and vehicle-level performance data to identify delivery delays, missing GPS data, and operational trends, enabling faster performance monitoring.
Applied data-quality and PII-handling practices during data preparation and reporting, following organizational data privacy requirements.
